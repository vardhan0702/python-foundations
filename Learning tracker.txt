import csv

def readcsvfile(filename):
    try:
        with open(filename, "r") as file:
            reader = csv.DictReader(file)
            passed=0
            failed=0
            percentage=0
            total=0
            for row in reader:
                if row["status"]=="Passed":
                    passed+=1
                elif row["status"]=="Failed":
                    failed+=1
                total+=1
                percentage= (passed/total)*100
        return {"FileFound": "True","Passed" : passed, "Failed":failed, "Total":total, "Percentage":percentage}
    except FileNotFoundError:
        print("Error: The file does not exist.")
        return {"FileFound": "False","Passed" : 0, "Failed":0, "Total":0, "Percentage":0}

def evaltest(result):
    try:
        passed = 0
        failed = 0
        total = 0

            if item["status"]=="passed":

            elif item["status"]=="failed":

    except ZeroDivisionError:

Day 15 : Git & GitHub?
====================================================
1. CONCEPT

Every script you've written so far lives only on your laptop. If your laptop dies tomorrow, all 14 days of work disappear. 
Git solves this by tracking every change you make to your code over time — like a save history for your entire project. 
GitHub is where you store that history online, so it survives, and so you can show it to anyone as a portfolio.

Three core actions:

git add — mark files as ready to be saved
git commit — actually save a snapshot, with a message describing what changed
git push — upload that snapshot to GitHub
